## What we build

We build and maintain Drupal websites, alongside the tools that help our team keep them healthy. Our work spans site development, ongoing updates, automated quality checks and deployment tooling.

## Team toolkit

Quick links for Adaptive developers. **These repositories are private and require access** — sign in with your team account to open them.

| Repository | What you'll find |
| --- | --- |
| [Drupal CI · drupal-workflows](https://github.com/adaptive-web/drupal-workflows) | Reusable GitHub Actions workflows for PHPStan, Composer checks, CodeQL, dependency review and SonarQube. |
| [OpenCode · ai-workflows](https://github.com/adaptive-web/ai-workflows) | Shared OpenCode automation for pull request reviews, issue triage and `/oc` or `/opencode` commands. |
| [Sentrix](https://github.com/adaptive-web/sentrix) | Drupal updates control centre for monitoring Dependabot PRs, managing test plans and tracking approvals. |
| [Deployment scripts](https://github.com/adaptive-web/New-Deployment-Scripts) | Shared workflow scripts and a starting point for site deployment setup. |

### Working on a site?

Start with the site's README for local setup, testing and deployment instructions. For shared CI or OpenCode configuration, follow the documentation in the toolkit repositories above.
